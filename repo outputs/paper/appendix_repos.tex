\section{MOSIP Modules Analysed}
\label{app:modules}

Table~\ref{tab:modules} lists the twenty repositories in this study. Nine of
them also appear in the fifteen-module core set analysed by Agarwal and
Vasilescu~\cite{agarwal2025mosip}; those rows carry that report's module name,
and the remainder are named from their own documentation. The two selections
differ because the criteria differ: the earlier report selected the modules
that constitute a MOSIP deployment, whereas this study ranks by analysable JVM
source volume and excludes repositories with little or no compilable code.
Section~\ref{sec:selection} discusses the consequences.

\section{Per-Repository Statistics}

Table~\ref{tab:adoption} the detected adoption dates. Code size is measured at
the first and last SonarQube snapshot in the window. ``Sonar months'' is the
number of months for which a snapshot exists, against ``months'' of any
recorded activity; the gap is months in which nothing landed on the
integration branch, leaving no tree to analyse. \texttt{gist} recorded one
month of activity and no snapshot, and contributes to no estimate.
